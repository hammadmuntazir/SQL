# SQL Practice and Data Engineering

A collection of SQL fundamentals, query exercises, database connectivity practice, and introductory DuckDB lessons.

## Topics

- SELECT, filtering, joins, set operations, subqueries, and views
- DDL, DML, constraints, and date/string/number functions
- SQL interview-style exercises
- Python database connectivity examples
- Introductory DuckDB querying and data modeling

## Use

These files are individual practice scripts rather than a single end-to-end application. Open a script in a SQL editor compatible with its syntax and create any sample tables/data it expects before running it. Some files use SQL Server-style syntax, while the DuckDB lessons are a separate set of exercises.
